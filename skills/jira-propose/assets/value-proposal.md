# Template — value proposal

Section order and shape for a work item created by `jira-propose`. The conventions that govern every
template — structure only, no fixed language, no technology, optional sections omitted rather
than left blank — are in [reading a template](../../shared/references/templates.md).

---

# <The outcome, named as a change in the world>

## Outcome sought

<What becomes true if this is done, in one or two sentences. Not the thing to be built.>

## Who benefits

<The people or the role, named specifically enough that someone could go and ask them. What
they do today instead, and what it costs them.>

## How success is measured

<The observation or number that would change if this worked, and what it reads now. When it
cannot be measured, what would be observed instead.>

## Evidence

<The datum, metric or observation behind the proposal, with how it was obtained. One entry per
claim that could be checked.>

## Assumptions

<Every claim above with nothing behind it, stated as an assumption and attributed to whoever
holds it. Omit this section only when there are none.>

## Required fields not yet filled

<Fields this project marks required on creation that the answers do not cover, named so the
draft gate can raise them. Omit this section when there are none.>
