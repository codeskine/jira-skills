# Template — debt or risk record

Section order and shape for a work item created by `jira-assess`. The conventions that govern every
template — structure only, no fixed language, no technology, optional sections omitted rather
than left blank — are in [reading a template](../../shared/references/templates.md).

---

# <What the debt is, named as the thing that will cost — not as the work to repay it>

## What works today

<What currently functions, so that no reader mistakes this for a failure. One or two sentences.>

## What it costs to defer

<The toll being paid: whose time, how often, what it makes slower or riskier, and what it
already prevented. Measured where it can be measured.>

## Options

| Option              | What it takes                         | What it leaves           |
| ------------------- | ------------------------------------- | ------------------------ |
| <do nothing>        | <the toll, ongoing>                   | <what stays constrained> |
| <the cheap partial> | <order of magnitude, not an estimate> | <what it does not solve> |
| <the full change>   | <order of magnitude, not an estimate> | <what it unlocks>        |

<A recommendation may follow the table, marked as a recommendation. Deciding belongs to whoever
prioritises.>

## Technical impact

<What this touches and what it constrains for as long as it stands. What cannot be built, or can
only be built awkwardly, while it is there.>

## Measurements

<Each claim above that can be checked, with the number and how it was obtained. Where a claim
cannot yet be measured, what would have to be measured to settle it.>

## Required fields not yet filled

<Fields this project marks required on creation that the answers do not cover, named so the
draft gate can raise them. Omit this section when there are none.>

## Work type

<That this is a record of debt or risk, filed under a work type that does not name it because this
project's scheme has none. Omit this section when the project has a work type for this
intent.>
